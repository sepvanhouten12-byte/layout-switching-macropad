the macropad will have the following switches buttons and doohickies
15x acco cream yellow v3 keyboard switches in a 3x5 layout
3x 10k potentiometer fader 
1x 10k potentiometer

the macropad will be controlled by a raspberries pi pico 2w
it will have 1 or 2 18650 battery cells
the batteries will be charged by a tp4056
and it will have a ws2812b led chip to indicate mode 
it will be able to have different modes for work, gaming, ect.
all the keyboard switches faders and potentiometer will be mounted on a PCB with female pin headers for the pi pico.
the power modules will not be mounted on the PCB.
